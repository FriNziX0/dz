# Домашнє завдання: `string-to-address` у Solidity

**Дисципліна:** Розробка Fintech-додатків: Blockchain, криптовалюти, смарт-контракти, Solidity  
**Тема:** смарт-контракти, Solidity  
**Викладач:** Самойленко Денис Миколайович

## Завдання

Реалізувати мовою Solidity метод, який перетворює рядкове представлення Ethereum-адреси на її байтове представлення (`address`). Це зворотна операція до перетворення `address` у рядок.

## Реалізація

Контракт розміщено у [contracts/AddressConverter.sol](contracts/AddressConverter.sol). Основний метод:

```solidity
function stringToAddress(string memory value) public pure returns (address)
```

Метод приймає значення у форматі `0x` + 40 шістнадцяткових символів, наприклад:

```text
0xf39fd6e51aad88f6f4ce6ab8827279cfffb92266
```

Алгоритм послідовно зчитує кожен символ після префікса `0x`, перетворює його на шістнадцяткове число `0..15` і зсуває поточний результат на 4 біти. Після 40 символів утворюється 160-бітне значення, яке приводиться до типу `address`.

Контракт також перевіряє:

- довжину рядка (має бути 42 символи);
- префікс `0x` або `0X`;
- коректність кожного шістнадцяткового символу;
- великі й малі літери `A-F` / `a-f`.

При помилкових даних виконання завершується власною помилкою (`InvalidAddressLength`, `InvalidAddressPrefix` або `InvalidHexCharacter`).

## Тести

Тести знаходяться у [test/AddressConverter.ts](test/AddressConverter.ts) і перевіряють:

1. перетворення коректної адреси;
2. підтримку верхнього регістру та префікса `0X`;
3. помилку для рядка неправильної довжини;
4. помилку для недопустимого символу.
