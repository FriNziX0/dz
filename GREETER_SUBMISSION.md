# Домашнє завдання: обмеження доступу для `Greeter`

**Дисципліна:** Розробка Fintech-додатків: Blockchain, криптовалюти, смарт-контракти, Solidity  
**Тема:** Смарт-контракти  
**Викладач:** Самойленко Денис Миколайович

## Завдання

Реалізувати обмеження для смарт-контракту `Greeter`: текст привітання може змінювати лише власник контракту — вузол, що опублікував контракт. Реалізувати перелік вузлів, яким також дозволено змінювати текст.

## Реалізація

Контракт знаходиться у [contracts/Greeter.sol](contracts/Greeter.sol).

- У конструкторі `owner = msg.sender`; отже, власником автоматично стає адреса, з якої розгорнули контракт.
- Метод `setGreeting` доступний власнику та адресам із `isAllowedNode`.
- Лише власник може додати вузол методом `allowNode` або відкликати право методом `removeNode`.
- Метод `getAllowedNodes` повертає актуальний перелік дозволених вузлів.
- У разі порушення прав доступу контракт завершує виконання власною помилкою.

## Перевірка

Тести знаходяться у [test/Greeter.ts](test/Greeter.ts) та перевіряють власника, заборону для стороннього вузла, дозвіл для доданого вузла та відкликання доступу.

```powershell
npx hardhat build
npx tsc --noEmit
npx hardhat test mocha test/Greeter.ts
```
