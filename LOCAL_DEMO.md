# Локальна демонстрація Counter

Цей варіант не потребує Sepolia ETH, RPC URL або приватного ключа реального гаманця.

## 1. Запустіть локальну мережу

У першому терміналі в папці проєкту виконайте:

```powershell
npx hardhat node
```

Не закривайте цей термінал. Він покаже локальні тестові акаунти з 10 000 ETH і їх приватні ключі.

## 2. Додайте мережу до MetaMask

Додайте вручну мережу з такими параметрами:

| Поле | Значення |
| --- | --- |
| Назва мережі | Hardhat Local |
| URL RPC | `http://127.0.0.1:8545` |
| Chain ID | `31337` |
| Символ валюти | `ETH` |

Імпортуйте в MetaMask перший тестовий акаунт, використовуючи його приватний ключ із виводу `npx hardhat node`. Це ключ лише локальної мережі; не використовуйте ключі реальних гаманців.

## 3. Розгорніть Counter

У другому терміналі виконайте:

```powershell
npx hardhat ignition deploy ignition/modules/Counter.ts --network localhost
```

Скопіюйте адресу `CounterModule#Counter` з виводу. Модуль одразу збільшує лічильник до `5`, тому можна показати і успішне зменшення, і помилку на нулі.

## 4. Перевірте фронтенд

У третьому терміналі запустіть сайт:

```powershell
python -m http.server 8080
```

Відкрийте `http://localhost:8080`, оберіть у MetaMask **Hardhat Local**, підключіть гаманець, вставте адресу Counter і натисніть **Підключити Counter**.

Натисніть `dec()` один раз для успішного сценарію. Потім зменшіть значення до `0` і натисніть `dec()` ще раз для демонстрації помилки. Зробіть знімки відповідно до `SCREENSHOTS.md`.
